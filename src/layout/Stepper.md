## Props ที่ควรรู้

| prop | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `steps` | — | `{ label, description? }[]` |
| `current` | — | index ของขั้นที่ทำอยู่ **นับจาก 0** · ขั้นก่อนหน้า = เสร็จแล้ว (ติ๊กถูก) |
| `orientation` | `horizontal` | `vertical` = เรียงลงล่าง ป้ายข้างวงกลมเสมอ |
| `connector` | `fill` | `fixed` = เส้น 22×2 คงที่ จัดกลาง — ใช้ในโมดัล |
| `labelPlacement` | **`bottom`** | `bottom` = ตัวเลขบน ป้ายล่าง จัดกลาง · `end` = ป้ายข้างวงกลม (แนวนอนเท่านั้น) |
| `onStepClick` | — | ส่งมา ⇒ ขั้นที่**เสร็จแล้ว**กดย้อนได้ · ขั้นที่ทำอยู่/ข้างหน้ากดไม่ได้ |

ข้อความทุกตัวมาจากแอป — DS ไม่มี i18n
