## ยึดตาม Portal ตัวเดียว ไม่ใช่ค่าเฉลี่ย

เดิม component นี้เฉลี่ยจากสามแอปแล้วได้ของที่ **ไม่เหมือนแอปไหนเลย** — ที่เห็นชัดสุด
คือโชว์เส้นคั่นเป็นค่าเริ่มต้น ทั้งที่ 10 ใน 14 จอของ Portal ไม่มี
จึง re-ground ใหม่กับ Portal อย่างเดียว

วัดเทียบกับ `ConfirmModal` ของ Portal ในเบราว์เซอร์ **ตรง 12/12**:

| จุด | ค่า |
|---|---|
| กล่อง | กว้าง 530 · มุม 20 · pad 32 |
| หัวข้อ | 24px / 600 / lh 32 |
| หัวข้อ → คำอธิบาย | 8px |
| คำอธิบาย | 16px / 400 / **lh 26** |
| คำอธิบาย → ปุ่ม | 20px |
| ปุ่ม | สูง 44 · **16px / 500** · มุม 8 · ห่างกัน 16 |
| ขอบปุ่มยกเลิก | `rgb(137,149,161)` = `#8995a1` |
| เส้นคั่น | **ไม่มีใน component** — แต่ 4 จอวาดเอง (ดูหัวข้อถัดไป) |

⚠️ ตัวเลขชุดนี้วัดโดยฉีดคลาสของ `ConfirmModal` ลงในหน้า Portal ที่ล็อกอินแล้ว
**และต้องจำลอง `tailwind-merge` ด้วย** — ถ้าต่อ class ตรง ๆ จะอ่านได้ `rounded-sm` /
`font-semibold` จากคลาสฐาน ทั้งที่ของจริงคือ `rounded-lg` / `font-medium`

### เส้นคั่น — Portal มี แค่ไม่ได้อยู่ใน component

⚠️ **แก้ข้อสรุปเดิม** — เคยเขียนว่า "Portal ไม่มีเส้นคั่นสักจอ" ซึ่งผิด
`ConfirmModal` ไม่มีช่องให้ใส่ก็จริง แต่ **4 จากทั้งหมด 14 จอวาดเส้นเองใน `subtitle`**
และเป็น **สีตามโทน**:

| จอ | สี |
|---|---|
| `MoveSubUnitDialog` · `SubUnitInUseModal` | `bg-info-blue-primary` |
| `HolidayDeleteDialog` · `DeleteSubUnitDialog` | `bg-error-red-icon` |

ทั้งสี่ใช้คลาสชุดเดียวกันเป๊ะ: `mx-auto mb-4 h-1 w-12 rounded-full`
⇒ **48×4 · ห่างจากหัวข้อ 8 · ห่างจากคำอธิบาย 16**

ของเดิมที่นี่เป็น 40×4 ห่าง 10/8 ซึ่งไม่ตรงกับที่ไหน — แก้ตามที่วัดแล้ว
และชุดสีตามโทนก็ **ไม่ได้เป็นของที่ DS คิดขึ้นเอง** อย่างที่เคยเขียนไว้

ยังเป็น opt-in เพราะ 10 ใน 14 จอไม่มีเส้น

## สีข้อความ — ดำคงที่ ไม่ตามแอป

`--color-text-primary` ถูก alias ไปที่ `--color-brand` ⇒ ของเดิมหัวข้อกับปุ่มยกเลิก
เปลี่ยนสีตามแอป (Mediwork ออกมาเป็นเขียวมิ้นต์)

🔴 **ปุ่มยกเลิกเป็นสีแบรนด์ถึงสองชั้น** — `Button variant="secondary"` ให้ `text-brand`
มาอยู่แล้ว แล้วยังทับด้วย `text-text-primary` ซึ่ง alias ไป brand อีกที

| | ตอนนี้ | วัดได้ทั้งสี่ธีม |
|---|---|---|
| หัวข้อ | `text-text-black` | `rgb(25,25,25)` · 17.58:1 |
| คำอธิบาย | `text-text-black` | เหมือนกัน |
| ปุ่มยกเลิก | `text-text-black` | เหมือนกัน |

คำอธิบายเข้มเท่าหัวข้อตาม Portal โดยตั้งใจ — ในกล่องยืนยัน บรรทัดนั้นคือ "ผลที่จะเกิด"
(เช่น *ลบแล้วกู้คืนไม่ได้*) ไม่ใช่คำอธิบายประกอบ

`DialogTitle` ตัวหลักย้ายตามด้วย ไม่งั้น `Dialog` ธรรมดากับ `ConfirmDialog` จะคนละสี
บนจอเดียวกัน

## Mediwork ไม่เหมือน Portal

ตัวเลข Mediwork resolve จาก MUI 6.5.0 ใน `node_modules` ของ repo นั้นเอง
(theme override แค่ `fontFamily` · ค่าที่เหลือเป็น `sx` เขียนตายตัว)

| | Portal | Mediwork |
|---|---|---|
| กว้าง | 530 | **444** (`maxWidth="xs"`) |
| มุมกล่อง | 20 | **12** |
| หัวข้อ | 24 / **600** / `#283541` | 24 / **700** / `#374151` |
| เส้นคั่น | ไม่มีใน component · **4 จอวาดเอง สีตามโทน** 48×4 | **มี** ยกเว้นโหมดเตือน · ฟ้า `#60A5FA` **คงที่ทุกโทน** |
| ไอคอน | ส่งเองเมื่อไหร่ก็ได้ | เฉพาะ warning/error · 50px |
| คำอธิบาย | lh **26** · เข้มเท่าหัวข้อ | lh **22.4** · เทา `#6B7280` |
| ปุ่ม | สูง **44** · 16/**500** · มุม **8** | สูง **48** · 16/**600** · มุม **4** |
| ปุ่มยกเลิก | ขอบเทา ตัวอักษรเกือบดำ | ขอบ+ตัวอักษร **เป็นสีโทน** |
| ยืนยัน error | `#F52D0A` | `#F52D0A` ← **ตรงกันเป๊ะ** |
| ยืนยัน primary | `#1976D2` | `#0B77C6` |
| ยืนยัน success | `#0BB767` | `#1EA78F` |

🔴 **สองแอปตรงกันเป๊ะแค่แดงของโหมดลบ `#F52D0A`** ซึ่ง DS ยังใช้ `#e02c2c`
(จาก variant `destructive` ของ `Button`) — token `--color-error-red-icon` = `#f52d0a`
มีอยู่แล้ว แต่การเปลี่ยนกระทบปุ่มลบทั้งระบบ จึงยังไม่แตะ

## Figma ↔ โค้ด

| Figma | โค้ด |
|---|---|
| `Tone` = info / success / warning / danger | `tone` |
| boolean `Icon` | ส่ง `icon` มาหรือไม่ |
| boolean `Divider` | `divider` |
| boolean `Description` | ส่ง `description` มาหรือไม่ |
| boolean `Cancel` | `showCancel` |
| boolean `Content` | ส่ง `children` มาหรือไม่ |
| text `Title` / `Description text` | `title` / `description` |
| ป้ายปุ่ม (nested instance ของ `Button`) | `confirmLabel` / `cancelLabel` |
| — | `isLoading` · `errorMessage` · `onConfirm` คืน Promise — **ไม่มีใน Figma** |
| — | `size` — ทับความกว้างได้ แต่ของจริงใช้ 530 อย่างเดียว |

เฟรมอ้างอิงบนหน้าเดียวกัน: `โหมดแจ้งเตือน — ปุ่มเดียว` · `แบบมีไอคอน` ·
`แบบมีเส้นคั่น — ทรงของ Medimatch / Mediwork` · `Portal เทียบ Mediwork — คนละดีไซน์` ·
`ช่องเนื้อหาเพิ่มเติมใต้คำอธิบาย`

⚠️ ไม่มี Code Connect (ต้อง Figma Organization plan) — ตารางนี้คือตัวยึดแทน

## ค้าง

- [ ] `isLoading` ควรเป็น `loading` ตาม §4.5 (`Switch` ทำตัวอย่างไว้แล้ว) — กระทบ `ConfirmDialog` · `ConfirmCancelActions`
- [ ] แดงของโหมดลบ — สองแอปตรงกันที่ `#F52D0A` แต่ DS ใช้ `#e02c2c` ต้องเคาะว่าจะย้าย variant `destructive` ทั้งระบบไหม
- [ ] `children` ไม่บังคับ `text-left` ⇒ ฟอร์มที่ลืมสั่งเองจะจัดกึ่งกลาง
