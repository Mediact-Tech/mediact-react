# AppShowcaseDialog

หน้าต่าง "ตัวอย่างผลิตภัณฑ์ + ช่องทางติดต่อ" ของแอปที่ **ยังไม่เปิดใช้งาน** บนแอปที่ผู้ใช้ยืนอยู่ — กดการ์ดในลิ้นชักแอปแล้วเปิดกล่องนี้แทนการพาออกไป

| | |
|---|---|
| โค้ด | `packages/react/src/overlay/AppShowcaseDialog.tsx` |
| Storybook | `Overlay/AppShowcaseDialog` |
| Figma | node `2986:37737` (HR) · `3012:43436` (On cloud) · `2967:35789` (Refer) · `3012:45681` (Pay) — **ยังไม่มี component set ในไฟล์ DS** มีแต่แบบราย product |
| สถานะ sync | 🟡 ตัวเลขทุกค่าตรงกับ Figma (ผ่าน Portal ที่วัด DOM เทียบ node แล้วต่างไม่เกิน 0.6px) แต่ **ยังไม่ได้ทำเป็น component ในไฟล์ DS** — 2026-08-16 |
| 🔴 แก้ 2026-08-16 | ทรงของ **Refer** และ **Pay** เคยยกค่าของ HR มาใช้แล้วเปลี่ยนแค่ `x` ⇒ ภาพผิดขนาดทั้งใบทั้งสองผลิตภัณฑ์ · แก้ให้ตรง `APP_CATALOG` ของ Portal แล้ว และเพิ่มเทสตรึงค่าไว้ |

## API

```tsx
const [app, setApp] = useState<ShowcaseAppKey | null>(null);

<AppShowcaseDialog app={app} onClose={() => setApp(null)} locale={i18n.language.startsWith("en") ? "en" : "th"} />
```

ปกติ **ไม่ต้องเรียกเอง** — `TopNav.AppLauncher` ถือกล่องนี้ไว้ให้แล้ว ตั้ง `showcase: true` ที่ config ของแอปนั้นพอ

| prop | ค่า | ค่าเริ่มต้น |
|---|---|---|
| `app` | `"medihr" \| "medioncloud" \| "medirefer" \| "medipay" \| null` | — (`null` = ปิด) |
| `onClose` | `() => void` | — |
| `locale` | `"th" \| "en"` | `"th"` |
| `assetBaseUrl` | โฟลเดอร์ภาพ | `"/images/app-showcase"` |
| `assets` | ทับที่อยู่ภาพรายผลิตภัณฑ์ | — |

**จงใจไม่มี**

| prop ที่ไม่ทำ | เหตุผล |
|---|---|
| `labels` / `t` | 🔴 **กล่องนี้ถือคำแปลเอง** ต่างจาก `ContactSupportDialog` — ดู § การตัดสินใจ |
| `lineUrl` / `phone` | ใช้ค่ากลางจาก `ContactSupportDialog` เสมอ · เบอร์ที่ต่างกันระหว่างสองกล่องในแอปเดียวกันคือสิ่งที่ต้องกัน |
| `width` / `responsive` | ทรงเป็น px คงที่ตามแบบ · จอแคบให้เลื่อนดู ไม่ใช่ย่อจนไม่ตรงแบบ |
| `comingSoon` | นี่คือของที่มาแทนป้าย "เร็ว ๆ นี้" — ถ้ายังมีป้ายนั้นอยู่ก็ไม่ต้องมีกล่องนี้ |

## เทส

`AppShowcaseDialog.test.tsx` — 6 เคส · ล็อกสิ่งที่พังแล้วเงียบ:
คำโปรยเปลี่ยนตามภาษาโดยแอปไม่ส่งข้อความมา · ครบทั้ง 4 ผลิตภัณฑ์ทั้ง th/en · ช่องทางติดต่อเป็นชุดกลางชุดเดียวกับ `ContactSupportDialog` · ภาพอ่านจากโฟลเดอร์กลางและทับได้ · `app = null` แล้วไม่เหลืออะไรใน `document.body` · **ทรงของทั้ง 4 ผลิตภัณฑ์ตรงกับชุดที่ Portal ใช้ และไม่มีคู่ไหนใช้ทรงเดียวกัน**

🔬 **ยืนยันเทสด้วยการกลายพันธุ์แล้ว** — บังคับ `locale` เป็น `"th"` เสมอ ⇒ เคสภาษาแดงจริง (534/535) · เปลี่ยน `medirefer.preview.height` กลับเป็นค่าของ HR ⇒ เคสทรงแดงจริง แล้วคืนค่ากลับทั้งสองครั้ง

⚠️ happy-dom ไม่จัด layout ⇒ **ตัวเลข px พิสูจน์ในเทสไม่ได้** ต้องวัดใน Storybook
