## กดตรงกลางเปิดปฏิทิน

ส่ง `calendar` แล้วป้ายตรงกลางกลายเป็นปุ่มเปิด popover

**ค่าเริ่มต้นคือปิด** เพราะตัวเลื่อนแบบอ่านอย่างเดียวมีอยู่จริง — การ์ดตารางแพทย์
ส่ง `minDate === maxDate` เพื่อโชว์เดือนเฉย ๆ ถ้าเปิดปฏิทินให้อัตโนมัติ จอนั้นจะได้
ปฏิทินที่กดแล้วไม่มีอะไรเกิดขึ้น

`unit="month"` เปิดมาที่ **ตาราง 12 เดือน** และเลือกจบที่เดือนเลย

## สองโหมดของการ commit

| | เมื่อไหร่ใช้ | พฤติกรรม |
|---|---|---|
| ไม่ส่ง `confirmLabel` | มีแค่วันที่ต้องเลือก | กดวัน → `onChange` → ปิดทันที |
| ส่ง `confirmLabel` | ลิ้นชักถือมากกว่าวันที่ | กดวัน = **ร่าง** · commit ตอนกดปุ่มยืนยัน |

🔴 โหมดร่างไม่ใช่ของแถม — ของจริงในหน้า productivity ลิ้นชักถือ **ทั้งวันและเวร**
ถ้า commit ทันทีที่กดวัน หน้าจอข้างหลังจะโหลดใหม่ทั้งที่ผู้ใช้ยังเลือกไม่ครบคู่
และตัวเลขที่เห็นระหว่างนั้นเป็นของคู่ที่ผู้ใช้ไม่ได้ตั้งใจถาม

ร่างถูกตั้งใหม่จากค่าปัจจุบัน**ทุกครั้งที่เปิด** ไม่ใช่ค่าที่ค้างจากรอบก่อน (มีเทสล็อก)

## ช่องวางเนื้อหาเพิ่ม (`children`)

ทุกอย่างใต้ปฏิทินเป็นสล็อตเปล่า — DS ไม่รู้จักเวร แผนก หรืออะไรก็ตามที่แอปเอามาวาง
state ของสิ่งที่วางเป็นของผู้เรียกทั้งหมด รวมถึงการรีเซ็ตร่างของมันเองตอนเปิด
(ใช้ `onCalendarOpenChange` เป็นจังหวะรีเซ็ต — ดู story `วัน + เวร`)

กล่องนี้กว้าง **340 เท่าปฏิทินเป๊ะ** — ปล่อยให้ hug จะโดนแถวปุ่มที่ผู้เรียกวางมา
ดันจนลิ้นชักกว้างกว่าปฏิทิน แล้วปฏิทินจะลอยไม่เต็มกล่อง (วัดเจอ: 362 vs 340)

## ป้ายตรงกลางรับ ReactNode

ของจริงใส่สองส่วนในบรรทัดเดียว — **"18 พ.ค. 2569 · เวรบ่าย"** โดยครึ่งหลังเป็น
สีแบรนด์ เพราะมันคือครึ่งที่คนเปลี่ยนบ่อยที่สุด · ส่ง `label` เป็น JSX ได้ตรง ๆ

ไม่ส่ง `label` → format จาก `value` ด้วย `Intl` ตาม `locale` (ค่าเริ่มต้น `th-TH`
⇒ ปี พ.ศ.) และ `unit`

## Props ที่ควรรู้

| prop | ค่าเริ่มต้น | ทำอะไร |
|---|---|---|
| `value` · `onChange` | — | โหมด controlled · format + คำนวณ ‹ › ให้เอง |
| `unit` | `"month"` | หน่วยของป้ายและของการก้าว |
| `calendar` | `false` | กดตรงกลางเปิดปฏิทิน |
| `calendarTitle` | — | หัวข้อเหนือปฏิทิน |
| `children` | — | เนื้อหาใต้ปฏิทิน (กว้าง 340) |
| `confirmLabel` · `onConfirm` | — | เปิดโหมดร่าง + ปุ่มยืนยัน |
| `calendarOpen` · `onCalendarOpenChange` | — | คุมการเปิดปิดเอง |
| `calendarProps` | — | ส่งต่อให้ `Calendar` (`weekStartsOn` · `labels` · …) |
| `minDate` · `maxDate` | — | ปิดลูกศร **และ** ปิดวันในปฏิทินพร้อมกัน |
| `label` · `onPrev` · `onNext` | — | โหมด manual คุมเองทั้งหมด |
| `size` | `md` (40) | `sm` = 36 |
| `fullWidth` | `false` | ยืดเต็มความกว้างพ่อ |

ข้อความทุกตัวรวม `aria-label` มาจากแอป — DS ไม่มี i18n
