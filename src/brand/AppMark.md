# AppMark

เครื่องหมายประจำผลิตภัณฑ์ทั้ง 6 ตัว — ชุดเดียวที่ทุกแอปในตระกูลหยิบไปใช้ร่วมกัน

| | |
|---|---|
| โค้ด | `packages/react/src/brand/AppMark.tsx` · ตัวไฟล์อยู่ใน `brand/app-marks.ts` |
| Storybook | `Brand/App mark` |
| Figma | อาร์ตเวิร์กมาจากดีไซน์โดยตรง (ชุด 158×158 · 2026-08-25) ไม่ได้วาดใหม่ |
| สถานะ sync | ✅ 12 ไฟล์ = 6 แอป × 2 โทน ตรงกับที่ดีไซน์ส่งมาทุกเส้น |

## ที่มา

ทุกแอปต้องวาดเครื่องหมายของแอปอื่น (ลิ้นชักแอป · หัวราง · หน้าเข้าสู่ระบบ) แต่ก่อนหน้านี้
ต่างคนต่างคัดลอกไฟล์ไปไว้ใน `public/` ของตัวเอง ⇒ โลโก้ชุดเดียวกันเปลี่ยนคนละเวลา

วัดของจริงตอนย้ายเข้ามา: `mediact-hr-web` มี **19 ไฟล์** ใน `public/icons/` แต่ใช้จริง **3**
ที่เหลือเป็นซากจากตอนที่ยังวาดลิ้นชักเอง — ยังขึ้น deploy ทุกรอบและไม่มีอะไรบอกว่ามันตายแล้ว

## วิธีใช้

```tsx
import { AppMark } from "@mediact/react";

<AppMark app="medihr" tone="white" className="h-10 w-auto" />   // หัวราง — หมึกสูง 40 พอดี
<AppMark app="mediwork" className="size-8" />                    // บนพื้นขาว (primary = ค่าปริยาย)
<AppMark app="medipay" fit="grid" className="size-full" />       // วางเรียงกับมาร์กตัวอื่น
```

## `fit` — เต็มกล่อง หรือเว้นขอบไปเรียงกับเพื่อน

| ค่า | ทำอะไร | ใช้เมื่อ |
|---|---|---|
| `ink` (ปริยาย) | หมึกเต็มกล่อง ⇒ `h-10` แปลว่า **หมึกสูง 40** | มาร์กอยู่ตัวเดียวในพื้นที่ของมัน — หัวราง · หน้า login |
| `grid` | ย่อความสูงเหลือ **62.5%** เท่ากันทุกใบ | วางหลายแอปเรียงกัน — การ์ดในลิ้นชักแอป |

ค่าเริ่มต้นเป็น `ink` โดยตั้งใจ เพราะเป็นพฤติกรรมที่ `<img>` ปกติให้ ⇒ คนที่ไม่ได้ทำกริด
จะไม่โดนย่อโดยไม่รู้ตัว

ถ้าต้องการ**ที่อยู่ของรูป**ไม่ใช่ `<img>` (เช่น `og:image` · `<link rel="icon">` ·
`background-image`) ใช้ค่าดิบแทน:

```tsx
import { appMarks, appMarkLabels } from "@mediact/react";

const src = appMarks.medipay.primary;
```

## โทน — เลือกตามพื้นหลัง ไม่ใช่ตามธีมของแอป

| โทน | ใช้เมื่อ |
|---|---|
| `primary` (ปริยาย) | พื้นขาว/อ่อน — การ์ดในลิ้นชัก · รายการ · เนื้อหา |
| `white` | พื้นสีแบรนด์/เข้ม — หัวรางของ MediHR |

ดีไซน์ส่งมาสองไฟล์แยกตั้งแต่ต้น **ไม่ใช่ให้ย้อมสีเอา** — มาร์กหลายตัวเป็นสองสีในตัว
(MediHR = เส้น `#3A63E8` + จุด `#29B4EB`) ⇒ ย้อมสีเดียวทับไม่ได้อยู่แล้ว

## สิ่งที่ตั้งใจให้เป็นแบบนี้

- **`viewBox` ไม่ใช่ค่าที่ดีไซน์ส่งมา** — ต้นฉบับเป็น `0 0 158 158` เท่ากันทั้ง 12 ไฟล์
  ซึ่งเว้นขอบเปล่าไม่เท่ากัน (หมึกสูง **89.8–126.8** จาก 158 ⇒ ต่างกัน 41%) ⇒ ครอบกรอบใหม่
  ให้ชิดหมึกพอดีทุกไฟล์ · **ไม่มีพิกัดใน `<path>` ถูกแตะ** ตาม `CLAUDE.md` §8
- **🔴 ระยะขอบอยู่ที่ component ไม่ใช่ในไฟล์** — "ขอบเท่าไร" ขึ้นกับที่ที่วาด ไม่ใช่ตัวอาร์ตเวิร์ก
  รอบแรกทำกลับกัน คือ pad ลงไปในไฟล์ให้หมึกเป็น 0.625 ⇒ กริดสวย แต่**ทุกที่ที่ใช้มาร์กเดี่ยว
  ได้ของเล็กลง 37.5% เงียบ ๆ** · หัวรางของ hr-web หดทันทีที่สลับมาใช้ component นี้
  เพราะ `h-10` ที่เคยแปลว่า "หมึกสูง 40" กลายเป็น 25 ⇒ ย้ายมาเป็น `fit="grid"` แทน
- **หมึกเท่ากันที่ "ความสูง" ไม่ใช่ความกว้าง** — Mediwork/Medimatch เป็นทรงนอน
  MediOnCloud เป็นทรงตั้ง ⇒ บังคับให้เท่ากันทั้งสองแกนไม่ได้ ต้องเลือกหนึ่ง และความสูง
  คือแกนที่ตาใช้เทียบเมื่อไอคอนเรียงเป็นแถว
- **ฝังเป็น data URL ไม่ใช่ไฟล์ใน `public/`** — ~29 KB ในบันเดิลของทุกแอปที่ import
  แลกกับการที่แอปไม่ต้องคัดลอกไฟล์ไปวางเอง ซึ่งเป็นต้นตอของ 19 ไฟล์นั้น · ต่างจากภาพ
  showcase (224 KB → 307 KB เมื่อเป็น data URL) ใน `AppShowcaseDialog` ที่เก็บเป็น **ไฟล์**
  ใน `assets/` ของแพ็กเกจแทน เพราะฝังแล้วบันเดิลโตขึ้น 76% — อยู่ใน DS เหมือนกัน
  แค่คนละวิธีแจก (ดู `assets/README.md`)
- **`min-h-0` ติดมาให้เสมอ** — `<img>` ที่เป็น flex item มี `min-height: auto` ซึ่งยอมให้มัน
  โตเกินกล่องตามอัตราส่วนของไฟล์ แม้สั่ง `h-full` แล้ว (วัดจริง: ได้กล่อง 32×45.55 ในช่อง
  32×32 ⇒ ทะลุกรอบมนของการ์ด) เป็นกับดักที่ผู้เรียกใช้ไม่ควรต้องรู้เอง

## 🔴 กำหนดขนาดด้วย inline style ไม่ใช่คลาส ถ้าแอปนั้นมี CSS unlayered

`mediact-web-backoffice` (Mediwork) มี `img{max-width:100%;height:auto}` ใน `styles/globals.css`
แบบ **ไม่มี layer** ⇒ กฎนั้นชนะ utility ของ Tailwind **ทุกตัวไม่ว่า specificity เท่าไร**
เพราะ CSS cascade ให้ unlayered ชนะ layered เสมอ

```tsx
<AppMark app="medipay" className="h-12 w-auto" />              // ❌ ถูกกลืนใน Mediwork
<AppMark app="medipay" style={{height: 48, width: 'auto'}} />  // ✅ แน่นอนทุกแอป
```

วัดบนจอจริง (2026-08-25): โลโก้ในกล่อง showcase ที่สั่ง `h-full` ได้ความสูง **126px** แทนที่จะเป็น
**49px** — ใหญ่เกิน 2.6 เท่าจนทับพาดหัวข้างล่าง · อาการนี้โผล่เฉพาะ Mediwork ส่วน hr-web กับ
Portal ปกติ ทำให้หาสาเหตุยากถ้าไม่รู้เรื่อง unlayered มาก่อน

`fit="grid"` ไม่มีปัญหานี้เพราะมันสั่งความสูงเป็น inline style อยู่แล้ว

## บันทึกการตัดสินใจ

| วันที่ | เปลี่ยนอะไร | ต้นทุนที่ยอมรับ |
|---|---|---|
| 2026-08-25 | ย้ายเครื่องหมายทั้ง 6 แอปออกจาก `navigation/_app-icons/` มาเป็น API สาธารณะ พร้อมชุดไฟล์ใหม่จากดีไซน์ (12 ไฟล์ · 2 โทน) | บันเดิลของทุกแอปที่ import DS แบกเครื่องหมายครบชุด แม้จะใช้แค่ตัวเดียว |
| 2026-08-25 | `medipay` เลิกเป็น PNG | ต้องพึ่งไฟล์ SVG จากดีไซน์ — แต่ได้คมทุกขนาดและเติมขอบ viewBox ได้เหมือนตัวอื่น (ชุดใหม่รวม 29 KB น้อยกว่าชุดเก่า 6 ไฟล์ที่ 37 KB) |
| 2026-08-25 | `inkScale` รายแอปที่ `AppLauncher` ถูกถอดทิ้ง | เหลือเลขเดียว (62.5%) ใน `AppMark` ที่ใช้กับทุกใบ — ทำได้เพราะไฟล์ชิดหมึกหมดแล้ว ⇒ ไม่ต้องมีตัวเลขชดเชยรายแอปอีก |
| 2026-08-25 | ระยะขอบย้ายจากไฟล์มาเป็น prop `fit` | ผู้เรียกใช้ต้องรู้ว่ากำลังวางมาร์กเดี่ยวหรือวางเรียง — แลกกับการที่ `h-10` มีความหมายตรงตัวอีกครั้ง |

## ยังไม่ได้ทำ

- **ไม่มี wordmark (โลโก้เต็มพร้อมตัวหนังสือ)** — ชุดนี้เป็นมาร์กจัตุรัสล้วน แอปที่ต้องการ
  wordmark (hr-web ใช้ `medi-hr-logo.svg` อยู่) ยังต้องเก็บไฟล์เอง
- `mediactLogoDataUrl` (โลโก้ MediAct เต็ม) ยังอยู่ที่ `navigation/_app-icons/data.ts` ที่เดิม
  — คนละเรื่องกับเครื่องหมายรายผลิตภัณฑ์ และยังไม่มีใครนอก `TopNav` ขอใช้
- `medistock` / `medicare` ยังไม่มีในชุด — ดีไซน์ยังไม่ส่งมา
