# EmptyState · ErrorState

สถานะ **ไม่มีข้อมูล** และ **โหลดไม่สำเร็จ** — โครงเดียวกัน ต่างที่ค่าตั้งต้น

| | |
|---|---|
| โค้ด | `packages/react/src/feedback/EmptyState.tsx` |
| Storybook | `Feedback/EmptyState` |
| Figma | หน้า `EmptyState` — **`<EmptyState>` (5 variant, ทั้งบล็อกเป็น component เดียว)** + `<State media>` (5) + เฟรมอ้างอิง 4 |
| สถานะ sync | ✅ ตรงกันทั้งสองฝั่ง (2026-08-09) |

## สำรวจของจริงก่อนออกแบบ

**53 ไฟล์ที่ต้องพูดว่า "ที่นี่ไม่มีอะไร" — หน้าตาไม่ตรงกันสักกลุ่ม**

| แอป | ทรงป้าย | สีพื้น | ไอคอน |
|---|---|---|---|
| Portal `EmptyState` | วงกลม `p-6` | `#e3f2fd` | ผู้เรียกกำหนดเอง 60px |
| MediHR `EmptyState` | **คัดลอกจาก Portal ทั้งไฟล์** | `#e3f2fd` | เหมือนกันเป๊ะ |
| MediHR `SectionEmptyState` | สี่เหลี่ยมมน 64 | `teal-50` | `teal-500` |
| Mediwork `EmptyState` | วงกลม 72 | `#D4F1EF` | **สีขาว** บังคับ 30px |
| Medimatch (ในตาราง) | ไม่มีป้าย | — | เทา opacity 20% |

🔴 **ไม่มีแอปไหนใช้ *รูป* เลยสักที่ — เป็นไอคอนล้วนทั้ง 53 ไฟล์**
(ค้นเจอ `<img>` 2 ไฟล์ ตรวจแล้วเป็นรูปโปรไฟล์ในตาราง ไม่ใช่ภาพประกอบ)
⇒ **ช่อง `image` เป็นของใหม่ ไม่ได้ยกมาจากของเดิม**

## สีพื้นตามแอป — token เดียว 4 ค่า

ของจริงใช้ 4 สีที่ **ไม่ตรงกับแบรนด์ตัวเองสักแอป** (Portal ใช้ฟ้า Material ทั้งที่แบรนด์เป็นสเลต ·
MediHR ใช้เขียวน้ำทะเลทั้งที่แบรนด์เป็นคราม) ⇒ ที่นี่ผูกกับ `brand/subtle` แล้วให้ธีมกำหนดค่า

**วัดสดใน Storybook ทั้ง 4 ธีม** (สลับที่แถบเครื่องมือ → `App`)

| แอป | `--color-brand-subtle` | พื้นป้ายที่วัดได้ |
|---|---|---|
| Portal | `#f0f9ff` | `rgb(240, 249, 255)` ✅ |
| Mediwork | `#e9faf7` | `rgb(233, 250, 247)` ✅ |
| Medimatch | `#e6f2f6` | `rgb(230, 242, 246)` ✅ |
| MediHR | `#ebedfe` | `rgb(235, 237, 254)` ✅ |

📌 **`brand` เป็นตัวเดียวที่ขยับตามธีม** — อีก 5 โทนเป็นสี**ความหมาย** (สำเร็จ/เตือน/ผิดพลาด)
ซึ่งต้องเหมือนกันทุกแอปโดยตั้งใจ · "ผิดพลาด" ต้องแดงเท่ากันทุกที่ ไม่ใช่แดงบ้างครามบ้างตามแบรนด์

⚠️ **บน Medimatch `brand/subtle` เท่ากับ `bg/surface` พอดี** (`#e6f2f6` ทั้งคู่) —
component วาดการ์ด `bg/default` ของตัวเองจึงปลอดภัย แต่ถ้าส่ง `className` ไปทับพื้นการ์ด
ป้ายจะกลืนหายไป

## API

```tsx
<EmptyState
  icon={<Inbox />}
  title="ยังไม่มีรายการ"
  description="กดปุ่มเพิ่มเพื่อสร้างรายการแรก"
  action={<Button>เพิ่ม</Button>}
/>

<ErrorState
  title="โหลดข้อมูลไม่สำเร็จ"
  description="ระบบเชื่อมต่อไม่ได้ชั่วคราว"
  onRetry={refetch}
  retryLabel="ลองใหม่"
/>
```

| prop | ค่า |
|---|---|
| `icon` | ไอคอน — วางในป้ายสีพื้น · **ขนาดถูกบังคับ** (`sm` 24 · `md` 32) |
| `image` 🆕 | รูป/ภาพประกอบ — **ชนะ `icon`** · ไม่มีป้ายโดยปริยาย |
| `tone` | `brand`(ตั้งต้น) `info` `success` `warning` `danger` `neutral` `none` |
| `mediaShape` | `circle`(ตั้งต้นของไอคอน) · `none`(ตั้งต้นของรูป) — **ไม่มีทรงเหลี่ยม** |
| `size` | `sm` ในการ์ด/ส่วนย่อย · `md` ทั้งหน้า |
| `mediaClassName` | ทางออกเมื่อต้องการขนาด/สีนอกเหนือจากที่กำหนด |
| `minHeight` | กันหน้าที่ว่างแล้วสั้นลงจนของข้างล่างกระโดด |
| `iconTone` ⚠️ | ชื่อเดิม ยังใช้ได้ แต่ `tone` ชนะ |
| `onRetry` `retryLabel` `error` | เฉพาะ `ErrorState` |

### ทำไม `image` รับ element ไม่ใช่ `src`

แต่ละแอปโหลดรูปคนละทาง — `next/image` ต้อง import จากฝั่งแอป DS ดึงเข้ามาไม่ได้

```tsx
image={<Image src={emptyBox} alt="" width={160} height={160} />}
```

### ทำไมบังคับขนาดไอคอน

ของจริงเคยมีจอที่พกไอคอนเทา 44px ของตัวเองมาแล้ว**รับดีไซน์ครึ่งเดียว** —
Mediwork เขียนคอมเมนต์เตือนเรื่องนี้ไว้ในโค้ดตัวเองด้วย

บังคับที่**ป้าย** ไม่ใช่ที่ตัวไอคอน: `.parent svg { }` ชนะ class ของลูกด้วย specificity
⇒ กันได้จริง ไม่ใช่แค่ขอความร่วมมือ · ต้องการขนาดอื่นให้ใช้ `image` ซึ่งไม่ถูกบังคับ

## 🔴 หัวเรื่องใช้ `text-text-secondary` ไม่ใช่ `text-text-primary`

ใน `theme.css` (ชั้นที่ DS ยังกินอยู่) **`--color-text-primary` ถูก alias ไปที่ `--color-brand`**
⇒ หัวเรื่องกลายเป็นสีแบรนด์ตามธีม · เห็นชัดที่สุดตอนเป็นข้อความผิดพลาด:
พาดหัว *"โหลดข้อมูลไม่สำเร็จ"* ออกมาเป็น**สีเขียวมิ้นต์**บน Mediwork

ของจริงทั้ง 3 แอปใช้ดำ/เทาเข้มหมด — Portal `#374151` · Mediwork `#21272A` · MediHR `gray-900`
⇒ ที่นี่ใช้ **`text-text-secondary` (`#3f454a`)** ซึ่งเกือบตรงกับ Portal เป๊ะ
และเป็นโทนเดียวกับ `Heading` variant `Tone=heading` ใน Figma ⇒ สองฝั่งพูดเรื่องเดียวกัน
ไม่ใช่ "ดำ" ที่บังเอิญใกล้กัน

⚠️ **รากอยู่ที่ token ไม่ใช่ที่ component** — `semantic.css` ชุดใหม่ตั้ง `text-primary` เป็นเทาเข้ม
ไว้ถูกแล้ว แต่ DS ยังกิน `theme.css` (`CLAUDE.md` §9 ข้อ 3) · แก้ที่ token = กระทบทุก component
ที่ใช้ `text-text-primary` **และถึง Mediwork ทันที** ⇒ รอบนี้เลี่ยงเฉพาะจุด ไว้แก้ตอนย้าย token

### ตัวสลับธีมใน Storybook (ของใหม่)

เพิ่มแถบเครื่องมือ `App` เพราะ **token ที่เปลี่ยนตามแอปพิสูจน์ด้วยตาไม่ได้ถ้าดูได้ทีละธีม**

🔴 ไฟล์ธีมจริงใช้ `@theme {}` ซึ่ง Tailwind ปล่อยลง `:root` เสมอ ⇒ scope ตาม attribute ไม่ได้
⇒ ต้อง**คัดลอก**ค่าไป `preview.css` · การคัดลอกดริฟต์ได้ และเมื่อดริฟต์ **Storybook จะโกหก**
⇒ มี `theme-switcher.test.ts` เทียบทีละบรรทัดกับไฟล์ธีมจริง (6 เทส)

**สองอย่างที่ทำให้มันไม่ทำงานตอนแรก และไม่มีอะไรฟ้องเลย**

1. `preview.css` โหลดแค่ `theme.css` ผ่าน preset — **ไม่มี `--mx-*`** ⇒ บล็อก `[data-app]`
   ที่อ้าง `var(--mx-teal-50)` resolve ไม่ได้ แล้ว**ทับค่าเดิมให้ว่าง** = ป้ายโปร่งใสทั้ง 4 ธีม
   (แก้: `@import "@mediact/tokens/primitives"` — และต้องอยู่**บนสุด** ไม่งั้นถูกตัดทิ้งเงียบ ๆ
   เพราะ preset ถูก inline เข้ามาก่อน ทำให้ `@import` ที่ตามหลังผิดตำแหน่ง)
2. **dev server ที่รันค้างมาหลายวันไม่เคย generate utility `.bg-brand-subtle` เลย** —
   `getComputedStyle` คืน `rgba(0,0,0,0)` เหมือนกันหมด ซึ่งดูเหมือน token พัง แต่ที่จริง
   คือ Tailwind ยังไม่เห็น class ใหม่ · **restart แล้วถูกทันที**

## Figma

| | |
|---|---|
| **`<EmptyState>`** 🆕 | **ทั้งบล็อกเป็น component เดียว** · 5 variant (`Tone`) + property `Action` (BOOLEAN) |
| `<State media>` | ป้ายรูป · 5 variant (`Tone`) · ทรงกลมอย่างเดียว · property `Icon` (INSTANCE_SWAP) |
| เฟรมอ้างอิง | ไม่มีข้อมูล · ในการ์ด/ส่วนย่อย · โหลดไม่สำเร็จ · กรองไม่เจอ — **ทุกอันเป็น instance เดียว** |
| ถูกใช้ที่อื่น | หน้า `DataTable` — เฟรมสถานะว่าง 2 + ผิดพลาด 1 ใช้ `<EmptyState>` ตัวเดียวกัน |

### โครงข้างใน — instance ล้วน ไม่มีของวาดเอง

```
<EmptyState>  (Tone · Action)
├── ป้ายรูป   → <State media>  (Icon = INSTANCE_SWAP)
│                └── ไอคอนจากไลบรารีกลาง
├── หัวเรื่อง  → Heading  · Size=title-sm, Tone=heading
├── คำอธิบาย  → Text     · Size=body-md, Tone=muted
└── ปุ่ม      → Button   · Variant=secondary, Size=sm
```

🔴 **`Action` คุมทั้งปุ่มและระยะเหนือปุ่มพร้อมกัน** — ผูก boolean เดียวกับ 2 node
ปิดแค่ปุ่มจะเหลือช่องว่าง 32px ลอยอยู่

⚠️ **ข้อความแก้ที่ instance ที่ซ้อนอยู่ ไม่ใช่ที่ตัวนอก** — Figma ผูก component property
ข้ามชั้นไม่ได้ (`componentPropertyReferences` รับแค่ `characters`/`visible`/`mainComponent`
บน node ตรง ๆ) ⇒ **ถ้าจะให้พิมพ์หัวเรื่องได้จากตัวนอก ต้องเลิกใช้ `Heading`/`Text`
แล้วกลับไปเป็นข้อความวาดเอง ซึ่งขัดกับข้อที่ให้ทุกชิ้นเป็น component**
เลือกทางนี้ไว้ก่อน — เลือกชั้นในแล้วพิมพ์ได้ตามปกติ

⚠️ **ยังไม่มีแกน `Size` (sm/md) ใน Figma** — ฝั่งโค้ดมี แต่ `sm` ยังไม่เคยวัดจากจอจริง

📌 **`Tone=brand` เปลี่ยนตามโหมดของแอปใน Figma** เหมือนที่โค้ดเปลี่ยนตามธีม —
สลับโหมดแล้วดูป้ายแถวบนสุดของ variant set

🔴 **ทุกชิ้นในเฟรมเป็น component instance ไม่มีของวาดเองเลย** (2026-08-09)

| ชิ้น | component |
|---|---|
| ไอคอนในป้าย | `folder-open-03` · `file-05` · `search-01` · `alert-triangle` จากไลบรารีกลาง |
| หัวเรื่อง | `Heading` — `Size=title-sm, Tone=heading` |
| คำอธิบาย | `Text` — `Size=body-md, Tone=muted` |
| ปุ่ม | `Button` — `Variant=secondary, Size=sm` (`Icon left=false`) |

**ตรวจด้วยโค้ด** — ไล่ลูกตรงของทุกเฟรมแล้วนับตัวที่ไม่ใช่ `INSTANCE` (ยกเว้นตัวเว้นระยะ)
ได้ **0 ทั้ง 7 เฟรม** (หน้า `EmptyState` 4 + หน้า `DataTable` 3)

⚠️ **ค่าตั้งต้นของ `Icon` เป็น property ไม่ใช่ของ variant** ⇒ `Tone=danger` ก็ได้โฟลเดอร์
เป็นค่าเริ่มต้นเหมือนกัน ต้องสลับเอง · ใส่ `preferredValues` ไว้ให้เลือกคลิกเดียวแล้ว

⚠️ **จัดกึ่งกลางที่ text node ข้างใน instance ไม่ใช่ที่ instance** — `Heading`/`Text`
จัดชิดซ้ายมาในตัว · ถ้าเปลี่ยน instance เป็น HUG แล้วให้ auto-layout จัดกึ่งกลางแทน
ข้อความยาวจะล้นออกนอกกรอบเพราะไม่ตัดบรรทัด

📌 **ต่างจากตารางเต็มใบตรงที่โครงคงที่** — ตารางมีจำนวนคอลัมน์/แถวไม่เท่ากันทุกหน้า
จึงห่อเป็น component ไม่ได้ · แต่สถานะว่างมีโครงเดิมเสมอ (รูป → หัวเรื่อง → คำอธิบาย → ปุ่ม)
⇒ ห่อเป็นก้อนเดียวได้โดยไม่ต้องรื้อทุกครั้งที่ใช้

  (`md` วัดจาก Mediwork 72px)
- 🟡 **หัวเรื่องต่างจาก component อื่นใน DS** จนกว่า `text-primary` จะเลิก alias ไป `brand`
